# Schémas Froid & CTA

Éditeur de schémas de principe froid et traitement d'air, dans le navigateur.

- Bibliothèque de symboles issue du gabarit DWG (SH-GABARIT-Détails)
- Liaisons tracées à la main, mode ortho, couleurs par fluide
- Formes, textes, outil Couper (comme AJUSTER dans AutoCAD)
- Stations de vannes prêtes à poser, et stations personnelles
- Export PNG, SVG et projet .json

Ouvrir l'application : https://simonjosset.github.io/schemas-froid/
